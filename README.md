# My NixOS Dotfiles

NixOS + Home Manager flake for host **`aihole`**, user **`pradeep`**.
One repo declares the whole machine: system services, the Wayland desktop,
CLI tools, and Doom Emacs — all rebuilt atomically with one command.

```sh
rebuild   # sudo nixos-rebuild switch --flake ~/dotfiles#aihole
```

## Layout

| Path | Why it exists |
|---|---|
| `flake.nix` | Inputs (`nixpkgs`, `home-manager`, `noctalia`, `nix-doom-emacs-unstraightened`) and the single `nixosConfigurations.aihole` output. |
| `config.nix` | The `my` attrset: username, home dir, terminal/browser/file-manager, cursor, Obsidian vault. One place for user-specific values shared by all modules. |
| `configuration.nix` | System level: bootloader, locale/timezone, greetd + ReGreet login, GNOME/Niri sessions, audio (PipeWire), fonts (Fira + Noto incl. Kannada), IBus (US + Kannada itrans phonetic via `toggle-keyboard-layout`), OpenSSH, Tailscale, user account, system packages. |
| `assets/` | Vendored binary assets (ReGreet login background) so the greeter works offline and rebuilds stay hermetic. |
| `hardware-configuration.nix` | Generated by `nixos-generate-config`. Do not hand-edit. |
| `home.nix` | Home Manager entry point: imports every `homeModules/*` module, holds the **feature toggles** (`*.enable`), shared shell aliases, shell/CLI program config, and the Emacs daemon service. |
| `homeModules/*/` | One self-contained module per concern (see catalog below). Each exposes `options.<name>Module.enable` and does nothing unless enabled in `home.nix`. |
| `homeModules/doom/doom.d/` | Doom `init.el` / `config.el` / `packages.el`, built into the Nix store. |
| `flake.lock` | Pinned inputs. Update with `nix flake lock` / `nix flake update <input>`. |

## How it fits together

```
flake.nix ──inputs──▶ nixpkgs, home-manager, noctalia, nix-doom-emacs-unstraightened
    │
    ▼
nixosConfigurations.aihole
    ├── hardware-configuration.nix + configuration.nix   (system)
    └── home-manager (as NixOS module, useGlobalPkgs + useUserPackages)
            └── home.nix ──imports──▶ homeModules/*      (user)
```

`flake.nix` passes `inputs` and `my` (from `config.nix`) via
`extraSpecialArgs`, so every module can take `{ config, pkgs, lib, inputs, my, ... }`
and read shared values as `my.terminal`, `my.cursorName`, etc. instead of
hardcoding them.

## Module catalog

Desktops are mutually exclusive — keep exactly one of
`hyprland / niri / gnome` enabled (currently **niri**).

| Module | What it does | Why it exists as a module |
|---|---|---|
| `doom` | Declarative Doom Emacs via `nix-doom-emacs-unstraightened` (no `doom sync`, see below). | Doom needs its source, config, Emacs build, `$PATH` tools and fonts versioned together. |
| `niri` | Niri scrollable-tiling session: `config.kdl`, Super-key binds, Noctalia IPC for launcher/volume/media, random wallpaper from `~/Pictures/Wallpapers` on session start, screenshots via grim+slurp+swappy, GTK/Adwaita theming, ibus-daemon autostart + Mod+Shift+Space US/Kannada toggle. | Active desktop; binds reuse `my.terminal`/`my.browser` so switching apps touches one file. |
| `hyprland` | Alternative Hyprland setup (Lua-config syntax): monitors, master layout, animations, same Noctalia-integrated keymap as niri (incl. Mod+Shift+Space US/Kannada toggle), ibus-daemon autostart. | Drop-in desktop alternative; kept disabled but ready. |
| `gnome` | GNOME via pop-shell tiling + extensions (caffeine, vitals, burn-my-windows, user-themes) and dconf keybinds mirroring the Super-key scheme. Input sources: us + Kannada itrans (Super+Space). | Third desktop option with the same muscle memory. |
| `noctalia` | Noctalia shell bar (top, compact, Tokyo Night), dock off, wallpaper from `~/Pictures/Wallpapers` in random mode (Wallhaven off), clipboard history via cliphist. | Shared status bar / launcher / lock screen for the Wayland compositors. |
| `ghostty` | Ghostty terminal + `~/.config/ghostty/config` (FiraCode Nerd Font, Monokai Pro, borderless). | `my.terminal` points here, so all desktop binds open it. |
| `vesktop` | Vesktop (Discord) with a copied (not symlinked) `settings.json` forcing Wayland/Electron-Ozone flags. `force = true` because the app rewrites this file. | Declarative Wayland flags that survive app restarts. |
| `nixd` | `nixd` language server + `nixpkgs-fmt`, with `~/.config/nixd/config.json` pointing formatting at `nixpkgs-fmt`. | Editing this repo (and any Nix) with LSP + correct formatter. |
| `nodejs` | Node 26 + TS tooling (typescript-language-server, eslint, prettier, biome, bun). No toggle — always on. | Frontend work needs this regardless of desktop. |
| `nh` | `programs.nh` with auto-clean (`--keep-since 24h --keep 5`). | Nice rebuild UX and automatic `/nix/store` hygiene. |
| `idle` | `services.swayidle`: Noctalia lockscreen after 5 min idle + lock before sleep. | Screen locking on Niri, which has no built-in idle management. |

`home.nix` directly manages the rest (no module warranted): bash/zsh
(Oh-My-Zsh, shared aliases), direnv, fzf, fd, ripgrep, gh, htop, fastfetch,
tmux, git identity/aliases, and the `services.emacs` daemon.

## Doom Emacs

Doom is built by Nix, not by `doom sync`:

- `homeModules/doom/doom.d/` (`init.el`, `config.el`, `packages.el`) is copied
  to the Nix store as `doomDir`, so enabled modules always match the built
  Elisp dependencies (Doom profile `nix`; state in
  `~/.cache/doom`, `~/.local/share/doom`, `~/.local/state/doom`).
- `programs.doom-emacs` provides the `emacs` binary and sets
  `services.emacs.package` automatically — don't set an Emacs package in
  `home.nix` or you'll get a duplicate-definition error.
- Keybinding style: Doom leader menus, **no evil** (`(default +bindings
  +smartparens)`, corfu + vertico completion, eglot LSP).

Workflow:

```sh
# edit, then rebuild — never `doom sync`
vim homeModules/doom/doom.d/init.el
rebuild
doom doctor   # expect 0 errors; ~30 "couldn't find X" warnings are normal
              # (optional per-language formatters/LSP servers, install per-project)
```

Escape hatches: `~/.config/doom-local.el` (untracked, auto-loaded for
per-machine tweaks); Custom-save doesn't persist (store is read-only), so put
settings in `config.el`. New Doom module flags must exist in the locked Doom
source or the build fails — check with
`ls $(nix eval --impure --raw --expr "(builtins.getFlake \"$PWD\").inputs.nix-doom-emacs-unstraightened.inputs.doomemacs-modules.outPath")/modules/<category>/`.

## Workflows

```sh
rebuild                              # apply system + home changes
nh os switch ~/dotfiles              # same, via nh
nix flake update <input>             # bump one input, then rebuild
nixpkgs-fmt --check <file>           # repo formatter is nixpkgs-fmt, NOT nixfmt
git add <new-files>                  # required: flakes ignore untracked files
```

Adding a module: create `homeModules/<name>/default.nix` following the
`options.<name>Module.enable` + `lib.mkIf` pattern (copy `nh`), import it in
`home.nix`, add the toggle. See `AGENTS.md` for the full agent/maintainer
checklist.
